# Создание большого конспекта

Создай подробный структурированный конспект из большого текста.

## Принципы:

### 1. ПОЛНОТА
- Не упускай важные детали
- Сохраняй нюансы и оговорки автора
- Фиксируй примеры и кейсы

### 2. СТРУКТУРА

**Метаданные:**
- Источник
- Автор
- Дата
- Тема

**Краткое резюме (TL;DR):**
3-5 предложений с основной сутью

**Оглавление:**
Список разделов конспекта

**Основные разделы:**
Для каждого раздела:
- Заголовок
- Ключевые тезисы (bullet points)
- Важные цитаты
- Примеры и кейсы
- Мои заметки (если нужно отделить интерпретацию)

**Ключевые концепции:**
Словарь терминов и понятий из текста

**Связи и ссылки:**
На что автор ссылается, с чем полемизирует

**Практические выводы:**
Что можно применить

**Открытые вопросы:**
Что осталось непонятным или требует изучения

### 3. ФОРМАТИРОВАНИЕ
- Используй заголовки разных уровней
- Выделяй ключевые понятия **жирным**
- Используй > для цитат
- Нумеруй последовательности
- Используй списки для перечислений

### 4. ОБЪЕМ
Конспект должен быть достаточно подробным, чтобы по нему можно было восстановить основные идеи текста без обращения к оригиналу.

Текст для конспекта:
$ARGUMENTS
