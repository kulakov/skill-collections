# Создание скилла

Единая точка входа для создания нового скилла Lance. Имя скилла: $ARGUMENTS

Все шаги выполняй автоматически, по порядку.

## 1. Проверь уникальность имени

Сверь имя среди:
- `~/.claude/commands/*.md` (включая симлинки, исключая `_archive/`)
- `~/.claude/skills/*/SKILL.md`
- `~/.claude/commands/*.md` — проектные

Если имя занято — предложи альтернативу и останови.

## 2. Спроси у пользователя (по одному вопросу)

1. Что скилл делает? (→ description)
2. Какие алиасы? (формат `l-X-name`, где X — категория)
3. Простой (commands/) или сложный со структурой (skills/)?

## 3. Напиши pushy description

По правилам из глобального CLAUDE.md:
- Перечисли конкретные фразы и контексты, когда скилл нужен (рус + англ)
- Укажи когда НЕ нужен → с указанием, какой скилл вместо
- Покрой edge cases: casual speech, English, типичные опечатки

## 4. Создай файл скилла

- **Простой** → `~/.claude/commands/<name>.md`
- **Сложный** → `~/.claude/skills/<name>/SKILL.md` (+ подпапки references/, templates/ при необходимости)

Frontmatter: `description:` (pushy) + `aliases:`.

## 5. Зарегистрируй в каталоге

Добавь строку в `~/10-CLAUDE/SKILLS_CATALOG.md` — в правильную категорию по префиксу:

| Префикс | Категория |
|---------|-----------|
| `l-a-*` | Аналитика |
| `l-t-*` | Think |
| `l-c-*` | Контент |
| `l-g-*` | Games |
| `l-k-*` | Knights |
| `l-s-*` | Store |
| `l-d-*` | Do |
| `l-w-*` | Write |
| `l-x-*` | Утилиты |

## 6. Если скилл сложный — добавь в библиотеку стилей

Согласно глобальному CLAUDE.md: новый сложный скилл → добавить строку в `~/.claude/style-library.html`.

## 7. Выведи чеклист

```
[x] Файл создан: <path>
[x] Каталог обновлён
[ ] Проверь description — достаточно ли pushy? (прогони /l-s-skill-doctor при сомнениях)
```

## Примеры

- `/l-s-skill-add my-new-skill` — создать новый скилл с нуля
- «оформи это как скилл» — после полезного действия завернуть его в повторяемую команду
