# Track Prep — подготовка к сессии

$ARGUMENTS — имя команды. Если пусто — спроси.

## Процесс

### Шаг 0: Норма (собрать материалы из гита)

Запусти субагента-Норму (Task tool, промпт: `~/.claude/skills/track/agents/norma.md`) с задачей: собрать всё, что понадобится для подготовки. Прочитать из `teams/<team-name>/`:
- `STATE.md` — текущее состояние, цепочка блокеров, гипотезы
- `BOTTLENECK_LOG.md` — что снято/не снято, контракт прошлой сессии
- **Транскрипт предыдущей встречи** — последний файл в `transcripts/` (если нет локально — `gh api repos/kulakov/granola-notes/contents/notes`)
- Последняя запись `DIARY.md`
- Декомпозиция цели / план (из STATE.md секции «Декомпозиция цели»)

Передать всё это дальше как контекст. Транскрипт прошлой встречи — обязателен: на нём строятся recall и проверка «новизны» вопросов.

### Шаг 1: Оркестратор (цепочка блокеров + контракт)

Запусти `/track-orch $ARGUMENTS` — получи:
- Цепочку блокеров (от текущего состояния до эндгейма)
- Контракт сессии (всегда = "снимаем блокер 0")
- Оценку гипотез (есть ли Type B/C?)

### Шаг 2: Трекер (вопросы)

Запусти субагента-Трекера (Task tool, промпт: `~/.claude/skills/track/agents/tracker.md`) с задачей PREP:

Входные данные:
- STATE.md команды (включая цепочку блокеров)
- **Транскрипт предыдущей встречи** (от Нормы)
- Последняя запись DIARY.md
- Контракт сессии от Оркестратора (блокер 0)

Задание:
- Подготовить вопросы по блокеру 0 (снято? что мешает?)
- **Вопросы должны быть НОВЫЕ:** свериться с прошлым транскриптом — не переспрашивать то, на что уже ответили; идти от того, что команда обещала сделать («в прошлый раз вы сказали X — сделали?»)
- Подобрать фреймворк из `~/.claude/skills/track/frameworks/`
- Проверить actions с прошлой сессии (выполнены ли)

### Шаг 3: Супервизор (мета-анализ)

Запусти субагента-Супервизора (Task tool, промпт: `~/.claude/skills/track/agents/supervisor.md`) с задачей PREP:

Входные данные:
- STATE.md (полный)
- Контракт сессии

Задание:
- Мета-картина (N/12 сессий, % прогресса)
- Алерты (застревание, drift, цикличность)
- Проверка связи контракта с целью трека

[Формулировка — всегда про блокер 0]
