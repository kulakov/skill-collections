# Подписки — управление таблицей

Работа с Google Sheet подписок через MCP google-sheets.

## Spreadsheet

- **ID:** `<id-документа>`
- **Sheet:** `Sheet1`

## Структура таблицы

| Колонка | Содержание |
|---------|-----------|
| A | Категория (AI, Хранилище, Инструменты, Развлечения, Рутины) |
| B | SUM(EUR/мес) по категории |
| C | =B*12 (годовая сумма категории) |
| D | Название сервиса |
| E | Период (мес, год, 3 мес) |
| F | Цена в оригинальной валюте |
| G | Валюта (USD, EUR, PLN, RUB) |
| H | Курс к EUR (сколько единиц за 1 EUR) |
| I | =F/H (цена в EUR) |
| J | EUR/мес (мес: =I, год: =I/12, 3 мес: =I/3) |
| K | =J*12 (годовая сумма) |

Последняя строка — ИТОГО с SUM по J и K.

## Инструкции

1. **Прочитать:** `get_sheet_data` с spreadsheet_id и sheet
2. **Добавить подписку:** вставить строку через `batch_update` (insertDimension), заполнить данные, обновить SUM формулу категории
3. **Изменить цену:** `update_cells` на нужную ячейку
4. **Удалить:** удалить строку через `batch_update` (deleteDimension), обновить SUM

## Безопасность

- Работай ТОЛЬКО с этим spreadsheet_id
- НЕ используй list_spreadsheets, list_folders, share_spreadsheet
- НЕ создавай новые таблицы без явного запроса пользователя
- При любом сомнении — спроси пользователя

## Аргумент $ARGUMENTS

Пользователь передаёт что нужно сделать: "покажи", "добавь X за $Y/мес", "удали Z", "обнови курсы".
