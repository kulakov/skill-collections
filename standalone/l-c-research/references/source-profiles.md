# Source Profiles — доверие к источникам и свежесть по кластеру

Фаза 3-4: у каждого кластера своя система доверия. Нельзя мерить индустрию академической линейкой и наоборот. Для каждого выбранного кластера собери профиль.

## Профиль источников кластера

1. **Что считается надёжным.**
   - Академия: peer-review журналы (квартиль), мета-анализы, систематические обзоры, Cochrane (для клиники), препринты — с пометкой «предварительно».
   - Индустрия: доклады профильных конференций (GDC, NeurIPS-воркшопы, отраслевые саммиты), постмортемы, технические блоги ведущих команд, открытые бенчмарки, отчёты регуляторов/ассоциаций.
2. **Что считается мусором/слабым.** Новостные пересказы вместо первоисточника, маркетинговые whitepapers без данных, анонимные блоги, вторичные агрегаторы.
3. **Где искать.** 3-5 профильных баз/площадок на кластер. Академия: Google Scholar, PubMed, arXiv, Web of Science, Semantic Scholar. Индустрия: профильные архивы докладов, отраслевые порталы, репозитории, базы патентов.
4. **Иерархия доказательств кластера.** Что бьёт что (напр. мета-анализ > RCT > когорта > мнение эксперта; в индустрии — воспроизведённый бенчмарк > один кейс).

## Свежесть данных (вход для Фазы 4)

Предлагай дефолтный временной коридор **по кластеру**, исходя из того, где фронтир:
- Быстрые поля (прикладной ML, перформанс-маркетинг, геймдизайн live-ops): последние 1-3 года, старое быстро устаревает.
- Зрелые поля (классическая психология, статистика, экономика): канон может быть 10-30 лет, плюс свежие репликации.
- Клиника/доказательная медицина: свежие систематические обзоры + базовые RCT любого года.

Всегда спрашивай подтверждение у пользователя; коридор — на кластер, не общий.
