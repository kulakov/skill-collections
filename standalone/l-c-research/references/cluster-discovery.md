# Cluster Discovery — как картировать КТО изучает проблему

Цель Фазы 1: до любого поиска построить карту «кластеров» — областей знания (наук и индустрий), которые занимаются проблемой, с их методиками и лексиконом.

## 1. Науки (всегда)

Спроси себя: проблема — это про что на уровне механизма? Перечисли дисциплины, которые изучают этот механизм с разных сторон.
- Идти от явления, а не от привычной дисциплины. Пример: «удержание игрока» = психология мотивации + поведенческая экономика + HCI + статистика выживаемости + теория игр.
- Включать и фундаментальные, и пограничные/гибридные поля (напр. «нейроэкономика», «вычислительная социология»).
- Для каждой науки: какие у неё канонические подходы к этой проблеме (теории, модели, методы измерения).

## 2. Индустрии (обязательно, не опционально)

Многие проблемы лучше изучены практиками, чем академией. Спроси:
- Для каких индустрий эта проблема — хлеб? Кто там теряет деньги/выигрывает на её решении?
- Кто внутри индустрии её **изучает системно** (R&D-отделы, лиды, авторы докладов/постмортемов, бенчмарк-команды)?
- Примеры доменов, где индустрия часто опережает академию: геймдизайн, реклама/перформанс-маркетинг, алготрейдинг, UX/продукт, прикладной ML, кибербез, спортивная наука, кулинария/ферментация.

Правило: **науки смотрим всегда; индустрии добавляем поверх.** Не заменять одно другим.

## 3. Методики по кластеру

Для каждого кластера (наука или индустрия) зафиксируй:
- Как они формулируют проблему (их рамка и термины).
- Какими методами работают (эксперимент / мета-анализ / A-B-тест / постмортем / симуляция / полевые данные).
- Что считают «доказательством» (это вход для Фазы 3 — калибровки источников).

## 4. Ключевые слова

- Один и тот же феномен называется по-разному в разных кластерах — собери термины **на кластер**.
- Для каждого: основной термин + синонимы + смежные + англоязычный вариант.
- Готовь булевы запросы: `"term1" AND ("syn1" OR "syn2")`.
